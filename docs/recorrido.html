Por debajo
La página guarda en el navegador el usuario, la organización y qué quedó verificado de Fly.io y Claude; nunca llaves. Al montar otra app vuelve a mirar usuario y organización en la API de GitHub y, como la organización ya se conoce, comprueba en el paso 1 que el nombre está libre en ella. La llave de Fly y FLY_ORG ya están en la organización, así que la app nueva las hereda. En el PC, los ayudantes y las sesiones de GitHub y Fly siguen: el instalador no abre el navegador. Si Claude tiene permiso solo en «los repositorios elegidos», el instalador le añade el nuevo o dice dónde hacerlo. Hay un enlace con las cuentas para usarlas en otro navegador, y «Olvidar mis datos».
